ALÉATO — prototype PWA bilingue

Contenu:
- index.html : application web
- manifest.webmanifest : métadonnées d'installation
- sw.js : cache hors ligne
- icon.svg : icône provisoire

Pour tester:
1. Héberger le contenu du dossier sur un hébergement HTTPS (par exemple GitHub Pages, Netlify ou Vercel).
2. Ouvrir l'adresse HTTPS dans Chrome Android.
3. Menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil.

Important:
- Un fichier HTML ouvert localement ne peut pas activer toutes les fonctions PWA.
- Ce paquet n'est pas encore un APK/AAB et n'est pas publié sur Google Play.
- Avant publication, il faudra tester sur plusieurs appareils, ajouter une politique de confidentialité si nécessaire, vérifier le nom/marque et préparer le compte Play Console.
